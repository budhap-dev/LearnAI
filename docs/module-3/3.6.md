## The one idea

Lesson 3.2 built logistic regression: a weighted sum of the inputs, squashed into a score.
A neural network is that, **stacked**:

```diagram
neural-net
```

Each node in a layer takes a weighted sum of the previous layer's outputs and applies a simple
non-linear function (a "squash", or the even simpler *ReLU*: max(0, x)). Stack a few layers
and the network can bend its boundary any way the data needs. Stack many, feed it enough
data, and it can represent almost any function — text, images, sound, code.

Nothing else is new. **Training is the loop from Lesson 1.2** — loss, gradient, nudge —
automated across millions or billions of weights by *back-propagation*, which is just the
chain rule from calculus applied efficiently, layer by layer. The explorer below is a
two-parameter version of the exact same descent:

```explorer
gradient-descent
```

## Why deep learning won

For decades neural networks were one family among many and rarely the best. Three things
changed, together:

1. **Data.** Networks keep improving with more data long after classic models plateau. The
   internet supplied text and images at a scale nothing else could use.
2. **Compute.** The weighted sums are matrix multiplications, and GPUs do those in parallel
   extraordinarily well. Training that took months took days.
3. **Learned features.** Classic ML needs a person to design features (Lesson 3.2). Deep
   networks learn their own representations from raw pixels, audio or tokens — the early
   layers become edge detectors, syllable detectors, word-part detectors — and those learned
   representations are exactly the *embeddings* of Lesson 2.3.

Put together: on **unstructured data** — where nobody can hand-design good features and
there is a lot of it — deep learning is the only game. On **small, structured, tabular
data**, boosted trees still usually win: less data-hungry, faster, more explainable.

```check
You have 4,000 rows of tabular customer data and want to predict churn. A colleague proposes a deep neural network. Best response?
- Agree — deep learning is state of the art
- * Start with logistic regression and boosted trees; a network needs far more data to beat them here and is harder to explain
- Refuse to use ML at all
why: Networks win on large unstructured data because they learn features. On small tabular data, well-designed features plus boosting is faster, stronger and legible.
```

## From this picture to the models in this course

- **Embeddings (2.3)** are the vectors flowing between layers, taken from a network trained so
  that similar inputs land near each other.
- **A transformer (2.4)** is this network with one extra ingredient — attention — so each
  token's vector can be updated using the others. Stack it deep, train it on next-token
  prediction, and you have an LLM (2.6).
- **Fine-tuning (Module 10)** continues the gradient loop on your data, usually with most
  weights frozen and small adapter layers learning.
- **Inference cost (2.4, 9.3)** is these matrix multiplications, run once per token, which is
  why tokens are the unit of price and time.

So the whole course is this diagram, applied: a very large network, its learned vectors,
and the engineering around calling it.

```check
Someone describes an LLM as "a database of the internet". Using this lesson and Module 2, what is the more accurate one-liner?
- A search index over web pages
- * A very large neural network whose weights were fitted, by gradient descent, to predict the next token of internet-scale text
- A rule engine trained by experts
why: There is no lookup; there are learned weights. That is why it generalises, why it invents, and why it forgets nothing and remembers nothing exactly.
```

## What you do not need to know (yet)

The maths of back-propagation, the zoo of layer types, and the folklore of training tricks
are not required to build with these models. What you need is the picture — layers of
weighted sums, trained by gradient descent, learning their own features — and the judgement
about where it fits. If you later fine-tune or run local models (Module 10), the details
arrive with the task.

## What a senior engineer should take from this

- **A network = stacked weighted sums and squashes, trained by the same gradient loop.**
- **It won on unstructured data because of data, GPUs and learned features.** On small tabular
  data, boosted trees usually win.
- **Embeddings, transformers and LLMs are this picture at scale**; tokens are the unit of cost
  because the maths runs per token.
- **You do not need the maths to build well.** You need the picture and the judgement.

## Model answers (sketch)

1. Inputs → weighted sums → squash → repeat per layer → a score; compare with the truth,
   nudge every weight a little against the error, repeat over millions of examples.
2. Network (images), trees/logistic (tabular), embeddings + k-means (network-derived vectors,
   classic clustering), network/LLM (language).
3. Many valleys and plateaus mean the simple loop can stall or land somewhere poor — hence
   momentum, adaptive step sizes, learning-rate schedules and lots of empirical tuning.
